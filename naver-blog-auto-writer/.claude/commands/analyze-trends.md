붙여넣은 글 / 지시: $ARGUMENTS

1. 사용자가 제공한 상위노출 글(들)에서 **정량 세팅값**을 추출한다:
   - 글자 수, 사진 수, 동영상 유무, 제목 글자 수와 구조(키워드 위치·패턴)
   - 소제목 수, 인용구 수, 태그 수, 지도 첨부 여부
   - 도입부 길이, 문단당 줄 수
2. 여러 글이면 평균·범위로 정리한다.
3. data/trends.md에 날짜와 함께 **누적** 기록하고, "현재 권장 세팅" 섹션을 최신값으로 갱신한다.
4. CLAUDE.md 기본 세팅과 크게 다른 항목이 있으면 채팅으로 짚어준다 (trends.md가 우선 적용됨).

절대 규칙 5: 사용자가 제공한 글로만 분석한다 — 자동 수집 금지.
