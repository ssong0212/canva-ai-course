---
description: 벤치마킹할 블로그 글의 말투·구성·심리 전략을 학습해 style-profile.md에 저장
---

붙여넣은 글 / 지시: $ARGUMENTS

1. 사용자가 URL만 준 경우: 네이버 블로그 본문은 WebFetch가 차단될 수 있다 — 실패하면 재시도하지 말고 바로 본문 붙여넣기를 요청한다.
2. 글에서 **구조만 추출**한다 (문장을 베끼지 않는다 — 유사문서 방지):
   - 말투·어미 패턴, 문장 길이 리듬
   - 도입 후킹 방식 (손실 회피형/현장 몰입형/반전형/공감형 중 무엇인지)
   - 소제목 구성, 인용구 사용 패턴, CTA 위치와 방식
   - 심리 전략 (Yes-set, 권위 문구, 불안 자극, 공감 등)
3. 분석 결과를 data/style-profile.md에 **누적** 기록한다 (기존 내용을 지우지 말 것, 날짜와 출처 메모 포함).
4. 학습 요약을 채팅으로 보고한다.

절대 규칙 5: 사용자가 제공한 글로만 학습한다 — 자동 수집 금지.
