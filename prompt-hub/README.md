# Prompt Hub — 비즈니스 AI 프롬프트 라이브러리

팀과 프롬프트를 공유하기 위한 단일 파일 웹앱입니다. `index.html` 하나로 동작하며
서버·빌드 과정이 필요 없습니다. 파일을 브라우저로 열거나 아무 정적 호스팅
(GitHub Pages, Netlify, Vercel 등)에 올리면 바로 쓸 수 있습니다.

## 카테고리 (비즈니스 필수 역량 기준)

| 카테고리 | 내용 |
|---|---|
| 📋 PRD·기획 | PRD 초안, 유저 스토리·AC, 경쟁 분석, RICE 우선순위, 킥오프 문서 |
| 🧑‍💼 HR·인사 | 채용공고(JD), 구조화 면접, 성과 피드백, 30-60-90 온보딩, 사내 공지 |
| 🎨 이미지 제작 | 프리미엄 부유샷, 키프레임 이미지, 캐릭터 일관성, 썸네일, 무드보드 |
| 🎬 영상 제작 | 씬별 광고 스토리보드, 멀티샷 연결, 컷 정밀 분해(START/END), 3초 훅, UGC 대본 |
| ✍️ 콘텐츠·카피 | 블로그 글, SEO 최적화 글, 인스타 캐러셀, 뉴스레터, 랜딩페이지 카피 |
| 📊 시각화 자료 | 슬라이드 구조, 인포그래픽, 차트 선택, 플로우 다이어그램, 원페이저 |
| 🔢 데이터·분석 | 분석 계획, SQL, 설문 설계, KPI 체계, 엑셀 자동화 |

이미지·영상 카테고리의 프롬프트에는 실전 광고 제작에서 검증된 규칙이 반영되어
있습니다 — 노텍스트 규칙(AI 생성물에 텍스트 금지), 이미지 우선 파이프라인
(시작 프레임 이미지 → 영상), 3초당 1씬 분할, 멀티샷 연결 등.

## 기능

- **검색·필터** — 제목/태그/본문 전문 검색, 카테고리 칩, 즐겨찾기(⭐) 필터. `/` 키로 검색창 포커스
- **복사** — 카드 클릭 → 프롬프트 전체 복사. `[대괄호]` 변수는 보라색으로 강조
- **공유 링크** — 프롬프트가 URL 안에 인코딩된 링크를 생성. 받은 사람은 링크만 열면
  같은 프롬프트를 보고 자기 보관함에 저장할 수 있음 (서버 불필요)
- **내 프롬프트** — 추가/수정/삭제, 브라우저 localStorage에 저장
- **내보내기/가져오기** — 전체 프롬프트를 JSON으로 백업하고, 다른 사람의 JSON을 병합
- 라이트/다크 테마 자동 대응, 모바일 반응형

## 팀 공유 방법 3가지

1. **링크 공유** — 프롬프트 하나를 빠르게 전달할 때 (공유 링크 복사 버튼)
2. **JSON 교환** — 여러 개를 한 번에: 내보내기 → 파일 전달 → 가져오기
3. **호스팅** — 이 폴더를 GitHub Pages 등에 올려 팀 공용 라이브러리로 운영.
   시드 프롬프트를 늘리려면 `index.html`의 `SEED` 배열에 항목을 추가하면 됩니다.
