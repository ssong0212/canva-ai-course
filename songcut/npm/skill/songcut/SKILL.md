# songcut — 공백 0초 컷편집 + 쇼츠 변환

말하는 영상을 받으면 **공백(무음) 자르기 → 쇼츠(9:16) 변환 → 제목·자막 입히기**를 ffmpeg 로 한다. 이 스킬은 그 **틀과 도우미**다.

## 정직하게 먼저

- 공백은 **소리 크기**로 찾는다. 말을 알아듣고 「재미없는 부분」을 고르지는 않는다. 배경음악이 깔린 영상은 공백이 안 잡힐 수 있다.
- **자막을 자동으로 받아 적지 않는다**(음성 인식 없음). `.srt` 파일을 직접 주거나, 클로드가 대본을 보고 `.srt` 를 써 준다.
- 목소리·음악·업로드는 하지 않는다. 만들어진 mp4 를 직접 올린다.
- 필요한 것: `ffmpeg`, `ffprobe`, 한글 폰트(윈도우 맑은 고딕 · 맥 애플 SD 고딕 Neo · 리눅스 나눔고딕/Noto CJK). 없으면 `doctor` 가 알려 준다.

## 쓰는 법

```
node ~/.claude/skills/songcut/songcut.mjs doctor                           필요한 것 점검
node ~/.claude/skills/songcut/songcut.mjs info 강의.mp4                      길이·해상도·소리
node ~/.claude/skills/songcut/songcut.mjs cut 강의.mp4                       공백 자르기 → 강의_cut.mp4 + 강의_cut.json
node ~/.claude/skills/songcut/songcut.mjs cut 강의.mp4 --db -40 --min 0.6    더 조용한 곳만, 0.6초 넘는 공백만
node ~/.claude/skills/songcut/songcut.mjs shorts 강의_cut.mp4 --title "캔바 AI 3분 정리" --hook 12 --srt 자막.srt
                                                                            → 강의_cut_shorts.mp4 (1080x1920)
```

| 옵션 | 뜻 | 기본 |
|---|---|---|
| `--db` | 이보다 작은 소리를 공백으로 본다(낮을수록 덜 자름) | `-35` |
| `--min` | 이 초보다 긴 공백만 자른다 | `0.4` |
| `--pad` | 말 앞뒤에 남기는 여유(초). 말끝이 잘리면 늘린다 | `0.12` |
| `--title` | 첫 화면 위쪽 제목(줄바꿈은 실제 줄바꿈으로) | 없음 |
| `--title-sec` | 제목이 떠 있는 초 | `3` |
| `--hook` | 이 초부터 3초를 맨 앞에 한 번 더 붙인다(첫 3초 후킹) | 없음 |
| `--srt` | 입힐 자막 파일 | 없음 |

## 클로드가 일하는 순서

1. `doctor` 를 먼저 돌린다. 한글 폰트가 없으면 제목·자막 작업 전에 멈추고 알린다.
2. `info` 로 길이와 소리 유무를 본다. 소리가 없으면 공백 자르기는 못 한다고 말한다.
3. `cut` 을 기본값으로 한 번 돌리고, **결과의 줄어든 비율**을 보여 준다.
   - 30% 넘게 줄었으면 말끝이 잘렸는지 의심하고 `--pad 0.2` 나 `--db -40` 을 제안한다.
   - 거의 안 줄었으면 `--db -30` 을 제안한다.
4. 쇼츠를 원하면 `shorts` 를 돌린다. 자막이 필요하면 대본을 받아 `.srt` 를 쓴다 — **한 줄 14자 안쪽**, 한 자막 1~3초.
5. **결과를 직접 확인한다.** `ffmpeg -ss 1 -i 결과.mp4 -frames:v 1 확인.png` 로 프레임을 뽑아 열어 보고, 한글이 □ 로 깨지지 않았는지·자막이 화면 밖으로 나가지 않았는지 본다. 「끝」이라는 말만 믿지 않는다.
6. `_cut.json` 의 남긴 구간을 보여 주면 사람이 「여기는 살려 줘」라고 고르기 쉽다.

## 웹 편집기와 같이 쓰기

같은 일을 브라우저에서 하는 쏭컷 웹 편집기(`songcut/web/editor.html`)가 있다. 웹에서는 파형을 보며 조각을 눌러 살리고 지울 수 있고, **「구간 JSON 내보내기」**로 받은 파일은 이 스킬의 `_cut.json` 과 같은 모양이다.

## 하지 말 것

- 원본 영상을 덮어쓰지 않는다. 결과는 늘 `_cut` · `_shorts` 를 붙인 새 파일이다.
- 남의 영상·음악을 허락 없이 잘라 쓰지 않는다.
- 렌더 시간을 짐작으로 말하지 않는다. 짧은 구간으로 먼저 돌려 걸린 시간을 본다.
