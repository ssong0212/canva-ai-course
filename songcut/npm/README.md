# creimeta-songcut — 공백 0초 컷편집 클로드 스킬

말하는 영상(강의·리뷰·브이로그)의 **공백을 자동으로 잘라 내고**, **1080x1920 쇼츠**로 바꾸고, **첫 3초 후킹 제목과 한글 자막**을 입히는 클로드 코드 스킬을 스킬 폴더에 놓습니다.

```
npx --yes creimeta-songcut
```

## 무엇이 놓이나

| 스킬 | 하는 일 | 자리 |
|---|---|---|
| `songcut` | ffmpeg 로 무음 구간을 찾아 잘라 내고(`cut`), 흐린 배경 세로 쇼츠로 바꾸고(`shorts`), 제목·자막(.srt)을 한글 폰트로 입힌다 | `~/.claude/skills/songcut/` |

깔고 나면 클로드 코드를 한 번 다시 켠 뒤 그냥 말하면 됩니다.

```
쏭컷으로 강의.mp4 공백 잘라 줘
방금 자른 걸 쇼츠로 만들어 줘. 제목은 "캔바 AI 3분 정리", 12초부터 후킹
```

## 정직하게

- 공백은 **소리 크기**로 찾습니다. 내용을 이해해서 지루한 곳을 고르지는 않습니다.
- **자막을 자동으로 받아 적지 않습니다.** `.srt` 를 주거나 클로드에게 대본으로 써 달라고 하세요.
- 목소리·음악·업로드는 하지 않습니다.
- `ffmpeg` 와 한글 폰트가 필요합니다. 설치기는 있는지만 알려 줍니다.
- 네트워크를 쓰지 않고 키도 필요 없습니다. 영상은 컴퓨터 밖으로 나가지 않습니다.

## 명령

```
npx --yes creimeta-songcut --check       깔지 않고 놓였는지·준비됐는지만 본다
npx --yes creimeta-songcut --dry-run     어디로 갈지 보여 주기만 한다
npx --yes creimeta-songcut --local       현재 폴더(.claude/skills)에 놓는다
npx --yes creimeta-songcut --force       이미 있어도 덮어쓴다
npx --yes creimeta-songcut --self-test   자기시험
```

## 사용권

크리메타쏭이 만든 스킬과 설치기입니다. 개인·사내·강의 실습 사용은 자유이고, 그대로 되파는 것은 허락하지 않습니다.
