클로드 코드 스킬

클로드에게 "공백 잘라 줘"라고 말하기

클로드 코드를 쓰신다면 스킬을 한 줄로 깔 수 있습니다. 깔고 나면 "쏭컷으로 강의.mp4 공백 잘라 줘"라고 말하면 됩니다.

① 명령 앞에 ! 붙이기 — 제일 확실합니다

맨 앞의 ! 까지 붙여 넣으세요. 중간의 --yes 를 빼면 「받아도 되나요?」에서 멈춥니다.

② 클로드에게 그냥 말하기

③ 터미널(검은 창)에서

윈도우: 윈도우키 → cmd 엔터 · 맥: command+스페이스 → 터미널 엔터

Node.js(nodejs.org)와 ffmpeg(ffmpeg.org)가 컴퓨터에 있어야 합니다. 깔고 나면 클로드 코드를 한 번 껐다 켜야 스킬이 잡힙니다. 폰이나 브라우저의 클로드 화면에서는 깔아도 내 컴퓨터에 남지 않습니다.

실제로 돌린 출력 (2026-10-28 · 12초 시험 영상)

$ npx --yes creimeta-songcut --self-test
songcut 자기시험
  ✓ 남길 구간 계산이 맞다 (공백 2곳 → 조각 3개)
  ✓ 12초 영상의 공백 4.5초를 실제로 잘랐다 12초 → 8.011초
  ✓ 스킬 원본 파일이 패키지에 있다
통과

$ node songcut.mjs cut talk.mp4

편집 시간을 줄여 줄 뿐입니다. 웹 편집기 내보내기는 영상 길이만큼(1배속) 걸립니다.

궁금한 점

영상이 서버로 올라가나요?

아니요. 웹 편집기는 브라우저 안에서만 처리하고, 클로드 스킬은 내 컴퓨터의 ffmpeg 로 처리합니다.

어떤 브라우저에서 되나요?

크롬·엣지를 권합니다. 크롬은 mp4 로, 그 밖의 브라우저는 webm 으로 내보낼 수 있습니다. 내보내는 동안 탭을 앞에 두세요.

한글이 □ 로 깨지면요?

웹 편집기는 Noto Sans KR 을 불러와 씁니다. 스킬은 맑은 고딕·애플 SD 고딕 Neo·나눔고딕을 찾아 쓰고, 없으면 doctor 명령이 알려 줍니다.

강의에서 수강생과 같이 써도 되나요?

무료 구성은 누구나 쓸 수 있습니다. 교안·실습 파일을 함께 쓰려면 강의 패키지를 확인하세요.
